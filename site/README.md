# HTML Publication

The final article is published as `site/index.html`. Markdown section files
remain the editable source of truth; the site build adds typography, charts,
and native synchronized video players.

Video files are not converted into static contact sheets. Each comparison uses
`<video controls playsinline>` and links the original MP4 generated by the
matched experiment.

The HTML builder and final page will be added after the article text is reviewed
and before experiment results are inserted.
